# gallery

메인 페이지 히어로의 사진 격자에 쓰이는 이미지 폴더입니다.

**이 폴더에 파일을 넣거나 빼면 그대로 반영됩니다. 코드는 고치지 않아도 됩니다.**
빌드할 때마다 여기 있는 사진 중 무작위로 최대 9장을 뽑아 3×3 격자로 보여줍니다.

## 사진 추가

파일을 복사해 넣고 다시 빌드하면 끝입니다. 파일명은 자유입니다.

```bash
cp ~/사진.jpeg web/src/assets/gallery/
cd web && yarn build
```

- 지원 확장자: `.jpg` `.jpeg` `.png` `.webp` `.avif` (대문자도 인식)
- 휴대폰 사진처럼 **EXIF 회전 정보가 있어도 알아서 똑바로 세워집니다**. 미리 돌려둘 필요 없습니다.
- 크기 조절·WebP 변환·썸네일 생성은 빌드가 알아서 합니다.

## 사진 삭제

파일을 지우면 됩니다. 9장 미만이 되면 있는 만큼만 표시됩니다.

## 권장 사항

- **긴 변 1200px 내외, 1장당 300KB 이하**로 줄여서 넣으세요. 원본 3~5MB 사진을 그대로 넣으면 저장소가 무거워집니다. 화질 차이는 격자에서 보이지 않습니다.
- 격자 칸이 **정사각형**이라 가운데가 잘립니다. 인물이 가장자리에 치우친 사진은 피하는 편이 좋습니다.
- 라이트박스(확대 보기)는 1200px로 표시되므로, 원본이 그보다 작으면 흐리게 보입니다.

용량 줄이기 예시:

```bash
cd web
node -e "
const sharp=require('sharp');
sharp('원본.jpeg').rotate().resize({width:1200,height:1200,fit:'inside',withoutEnlargement:true})
  .jpeg({quality:82,mozjpeg:true}).toFile('src/assets/gallery/새사진.jpg');
"
```

## 주의

격자에 쓸 사진은 반드시 **이 폴더(`gallery/`)** 에 두어야 합니다.
여기 있는 파일이 저장소에 실제로 커밋되는 사본이므로, 원본은 따로 보관하세요.
